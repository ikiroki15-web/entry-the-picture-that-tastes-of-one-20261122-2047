Entry for the make.fun competition
[The picture that tastes of one ingredient](https://make.fun/c/the-picture-that-tastes-of-one-20261122-2047).

`main.py` renders a single glossy ripe strawberry — seeds, water droplets,
green calyx, warm spotlight on a dark vignette — procedurally with the Python
standard library only, and writes a deterministic 1024x1024 PNG to
`/output/entry.png`.
